# Privacy Policy

Last updated: 2026-10-07

Compact Ready is a Claude Code plugin made of one instruction file (a skill). It contains no code, hooks, MCP servers or network calls.

## What it reads

When you run it, Claude reads what it needs to finish the current stage and describe it: your plan, todo list, task files and the project files used in the session. This is the same access Claude already has in your session.

## What it writes

One Markdown handoff file in your project: in the task folder, or `HANDOFF.md` in the project root. The file can contain whatever your session worked on, such as file names, decisions and error messages.

## What it sends

Nothing. The plugin adds no data flows. Claude Code itself sends your conversation to its model provider as usual; that is covered by the terms and privacy policy of Claude Code, not by this plugin.

## What the author collects

Nothing. There is no telemetry, analytics or account.

## How long data is kept

The handoff file stays in your project until you delete it. The plugin keeps nothing anywhere else.
